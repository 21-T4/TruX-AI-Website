Security-minded infrastructure behind TruX-AI

TruX-AI uses GitHub for source and repository workflows, Google Cloud Run for deployment, and secured cloud storage for conversation data.

The architecture is designed around controlled access to application and conversation data. Security remains an engineering responsibility across the product rather than a single feature.

The technology newsroom will document future changes to this architecture as they are made.
