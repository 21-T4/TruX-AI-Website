Security-minded architecture

Keep the important parts protected.

TruX-Omni-AI uses GitHub for source and repository workflows and Google Cloud Run for the application runtime. Chat history stays in browser storage; cloud-bucket storage is reserved for supported media assets rather than chat history.

✓ GitHub-backed engineering
Source code and repository actions are managed through authenticated GitHub workflows.
✓ Google Cloud Run runtime
Isolated, scalable application execution deployed on Google Cloud Run.
✓ Sign-in & browser-based chat history
Firebase Authentication protects sign-in; chat history stays in your browser, separate from media storage.
ARCHITECTURE SNAPSHOT PROTECTED
Source & repositories GitHub API & OAuth
Application runtime Google Cloud Run
Chat history Browser local storage
Media assets Cloud bucket storage
Identity & sign-in Firebase Authentication
